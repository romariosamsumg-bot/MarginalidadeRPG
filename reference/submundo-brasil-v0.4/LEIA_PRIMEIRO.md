# Marginalidade RPG — pacote para Claude Opus 5.5 (Alto)

Arquivos:
- `MARGINALIDADE_RPG_PROMPT_MESTRE_OPUS_5_5.md`: instruções completas (cole no chat do Claude).
- `Submundo-Brasil-v0.4.html`: base técnica conhecida para auditoria e reaproveitamento; NÃO modificar o Submundo Brasil original.
- `SUBMUNDO_BRASIL_BIBLIA_NARRATIVA_1.0.html`: história, personagens e missões para adaptar à identidade Marginalidade RPG.

## Uso sugerido no celular
1. Abra um chat no Claude com Opus 5.5 e raciocínio Alto.
2. Anexe os dois arquivos HTML presentes no pacote (ou envie o ZIP se o ambiente aceitar leitura de ZIP).
3. Cole o conteúdo do arquivo de prompt `.md` como mensagem.
4. Se existir uma versão do jogo mais recente que a v0.4, anexe-a também e indique que é a versão prioritária.
5. Solicite o ZIP com o projeto jogável e outro com o build de produção.

As ferramentas, a implementação e os testes serão realizados pelo agente que receber o prompt; este pacote não contém o novo jogo implementado.
